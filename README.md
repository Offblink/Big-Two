# Big-Two 锄大地（广东风味）

基于 Tkinter 的锄大地（Big Two）纸牌游戏，采用**广东/潮汕地区经典玩法**，支持人机对战。

## 家乡特色玩法

与标准国际版 Big Two 不同的广东玩法规则：

| 特色 | 说明 |
|------|------|
| **三条可出** | 三条是独立牌型，可单出、可压制对子 |
| **A 可作最小顺子** | 3-4-5-6-A 视为最小顺子（A 当 1），2 不入顺 |
| **牌型等级** | 单张 < 对子 < 三条 < 顺子 < 同花 < 葫芦 < 四带一 < 同花顺 |
| **花色定胜负** | 同点数比花色：黑桃 ♠ > 红心 ♥ > 梅花 ♣ > 方块 ♦ |
| **首回合限牌** | 首回合必须包含最小牌（方块 3 优先） |
| **报单提醒** | 对手只剩一张牌时会有语音化对白提醒 |

## 功能

- 2–4 人开局，2 人局可选 AI 对手
- 完整牌型校验：单张/对子/三条/顺子/同花/葫芦/四带一/同花顺
- 智能 AI：五张牌型冲突检测、报单防守（对手剩 1 张时优先出多张）、压制策略
- 游戏内对话区实时显示 AI 互动台词

## 运行

```bash
python 锄大地.pyw
```

## 依赖

- Python 3（仅标准库 tkinter）
